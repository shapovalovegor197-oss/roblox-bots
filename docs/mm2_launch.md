# MM2: где механика и как её запускать отсюда

Статус на 15.09.2026. Делит по [[proven-by-numbers-only]]: проверено / написано / не решено.

**Главное: механика MM2 живёт не здесь.** Она в отдельном проекте
`D:\claude projects\старпепс\roblox-swap` (`agents/mm2/`), вместе со складом —
каталогом, журналом операций, очередью выдачи. В brainbot осталось то, чем он и
является: глаза (захват, OCR), руки (ввод), клиент (поднятие аккаунта, мьютекс,
уступка ввода пользователю). Движок их импортирует; обратно — нет.

Запуск отсюда — через мост `python run.py mm2 <инструмент> …`
(`src/brainbot/mm2_bridge.py`). Мост процессный: он находит папку движка
(`--engine`, переменная `ROBLOX_SWAP` или сосед `../старпепс/roblox-swap`) и
запускает его инструмент тем же интерпретатором. Ничего не пересказывает —
инструменты движка разговаривают с человеком сами.

```powershell
python run.py mm2                                  # что есть
python run.py mm2 join --private <код> --attach     # зайти в приватку
python run.py mm2 probe --hwnd <id> --checklist     # посмотреть, ничего не нажимая
python run.py mm2 deal --hwnd <id> --scan           # снять инвентарь
python run.py mm2 deal --hwnd <id> --peer <ник> --give "Rune:legendary:1"
python run.py mm2 learn_icons --hwnd <id> --auto    # библиотека эталонов
```

## Что проверено живьём

- **Полный цикл обмена** — 15.09, оба направления, исход подтверждён дельтой
  инвентаря, а не видом экрана.
- **Геометрия** — 32 места сняты с живых кадров при окне 1280x720
  ([[roblox-window-size-is-calibration]]). Три места из старого списка в MM2 не
  существуют вовсе (поиск по нику, кнопка закрытия обмена, сетка инвентаря) —
  это записано в схеме, чтобы их больше не искали.
- **Инвентарь читается**: 17 позиций, опознано 10; остальные семь — честно не
  предметы (дефолтные нож с пистолетом, эффекты, радио, заголовки секций).
- **Стопка — один слот со счётчиком** «x3»: три Icewing лежат вместе.
- **Вид оружия узнаётся надеванием** — какая из двух надетых подписей сменилась,
  тот и вид. Так `Spectral` оказался пистолетом, а `Splash` ножом.
- **Картинки в Roblox** не грузились из-за DNS-фильтрации `tr.rbxcdn.com`, а не
  из-за настроек графики; починено переходом на DoH (`docs/MM2_IMAGES.md` в
  свопе). Без картинок эталоны бессмысленны.

## Что здесь устарело

- `src/brainbot/scenarios/mm2_trade.py` — **отставлен**. В командную строку он
  подключён не был, и команды `python run.py mm2 give …` из прежней редакции
  этого файла никогда не существовало. Оставлен как конспект механики 13.09;
  что из него перенесено и куда — в шапке самого файла.
- `data/mm2/layout.json` и `templates/mm2_*.png` — снимались под тот сценарий.
  Движок ведёт свою схему (`agents/mm2/data/layout.json`), и расходиться они
  будут дальше.

## Что не решено

- **Правило исхода при обрыве связи.** Что происходит с обменом, если клиент
  отвалится между «оба готовы» и подтверждением, — не измерено. До замера исход
  такой операции может быть только `unknown`.
- **Надёжность онлайна**: кик за ~20 мин простоя (err 278), два клиента на одной
  машине не уживаются (мьютекс держится живым процессом), машина сама
  выключается пару раз в день.
- **Целевое время сделки.** Без числа «быстро» непроверяемо.

Экономику (спред MM2 у Starpets 12%, маржа только после продажи принятого)
см. [[gg-cross-game-swap]] — это про рентабельность, не про технический запуск.
