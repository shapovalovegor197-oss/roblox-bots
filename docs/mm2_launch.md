## Что уже есть

  лидерборд → карточка игрока → Trade → 4 слота → ACCEPT → ARE YOU SURE →

- **Геометрия зафиксирована** — `data/mm2/layout.json`, окно 1280x720.

- **Шаблоны-якоря**: `templates/mm2_your_offer.png`, `mm2_are_you_sure.png` и др.

## Что проверить ПЕРЕД боевым прогоном (по порядку)

1. **Окно 1280x720.** Вся геометрия привязана к нему. `mm2 … --fix-size` или
   вручную. Иначе координаты кнопок поедут ([[roblox-window-size-is-calibration]]).
2. **`python run.py mm2 survey --hwnd <id>`** на открытом окне обмена — сверить,
   что OCR читает `YOUR OFFER`, `THEIR OFFER`, текст кнопки и статус партнёра.
   Это калибровка без гадания; правит `layout.json`, не код.
3. **Trade Requests: ON** в игре — иначе карточка не даст кнопку Trade.
4. **`find_player_row`** ловит ник в лидерборде (OCR нечёткий). Проверить на
   реальном нике контрагента; при промахе поднять/опустить `min_ratio`.
5. **Точка подтверждения (875,532)** и чтение фаз ACCEPT→ARE YOU SURE: первый
   прогон — `receive` в приватке со своим вторым аккаунтом, дешёвый предмет.
6. **Пруф.** Сейчас кадры до/после (`mm2_inv_before` + `mm2_before_confirm`).
   Дельту инвентаря числом ещё не читаем — глазами по кадрам.
7. **Редкость и стак при выкладке.** `give` выбирает предмет не «первой ячейкой», а
   по редкости (цвет плашки): `--rarity common/rare/legendary/godly` различает
   имена-двойники; `--qty N` кладёт стак (макс 4 слота). Палитра цветов —
   `data/mm2/layout.json → rarity.colors`, снята с живого кадра; **имена редкостей
   предположительные** — выверить на игре командой `python run.py mm2 survey-inv --hwnd <id>`
   (печатает по каждой ячейке имя, RGB и распознанную редкость). Стак поштучно —
   поведение реального стака в игре ещё не проверено.

## Блокеры «в работу» (не технический запуск, а сервис)

- **Заход к контрагенту не автоматизирован.** Сценарий начинается, когда оба уже
  в одном месте. Обмен удобнее в приватке ([[sab-private-server]]).
- **Надёжность онлайна** (перепроверить, память): кик за ~20 мин простоя (err 278),
  два клиента на одной машине не уживаются, машина сама выключается пару раз в день.
- **Приём входящего приглашения** не пишем: бот всегда инициатор, попап входящего
  обмена в кадрах 13.09 не снят — шаблон наугад не делаем ([[proven-by-numbers-only]]).

## Команды

```powershell
python run.py mm2 survey --hwnd <id>                 # калибровка окна обмена
python run.py mm2 give <ник> --item "Rune" --hwnd <id>   # отдать предмет
python run.py mm2 receive <ник> --item "Rune" --hwnd <id> # принять предмет
```

Экономику (спред MM2 у Starpets 12%, маржа только после продажи принятого)
см. [[gg-cross-game-swap]] — это про рентабельность, не про технический запуск.
